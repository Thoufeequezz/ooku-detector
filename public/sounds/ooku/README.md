# Ooku Audio Clips Directory

Place your audio files (`.mp3`, `.wav`, or `.ogg`) in this folder (`public/sounds/ooku/`).

## Filename Conventions by Roast Intensity:

### 1. Light Roasts (Intensity 1-3)
- `light-1.mp3`
- `light-2.mp3`
- `light-3.mp3`

### 2. Medium Roasts (Intensity 4-6)
- `medium-1.mp3`
- `medium-2.mp3`
- `medium-3.mp3`

### 3. Heavy Roasts (Intensity 7-8)
- `heavy-1.mp3`
- `heavy-2.mp3`
- `heavy-3.mp3`

### 4. Critical Roasts (Intensity 9-10)
- `critical-1.mp3`
- `critical-2.mp3`
- `critical-3.mp3`

### 5. Counter Attacks (COUNTER_OOKU)
- `counter-1.mp3`
- `counter-2.mp3`
- `counter-3.mp3`

---

*Note: The app will automatically detect and play these audio clips randomly whenever an Ooku roast is detected in chat!*
